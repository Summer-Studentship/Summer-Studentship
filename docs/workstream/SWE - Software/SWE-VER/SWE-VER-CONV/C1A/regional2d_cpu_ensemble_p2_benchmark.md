## Result

Best measured process count: `3`.

- Aggregate throughput: `0.103176` simulated s / wall s.
- Equivalent sequential wall speedup: `2.24x`.
- Median individual-case slowdown factor: `1x`.
- Gate: `A. ensemble parallelism sufficient - proceed to finer convergence`.

Secondary wall-speedup result: `4` processes gave `2.51x` versus sequential execution of the same short workloads, but its aggregate throughput was lower at `0.0927672` simulated s / wall s.

P1/P1B interpretation: the current intra-run OpenMP path is numerically validated but not useful for production acceleration on this workload. P2 therefore favours independent serial processes for immediate scheduling.
