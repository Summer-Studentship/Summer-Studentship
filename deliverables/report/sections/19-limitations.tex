\section{Limitations}

The G6 baseline is a theoretical and implementation closure, not a final predictive validation. Limitations include the use of available global terrain for G6, simplified rigid-barrier geometry, absence of observational calibration, no formal mesh/timestep convergence, and no official CAD-based porous or rubble-mound representation.

OpenFOAM provides the Local3D solver authority, so the repository evidence focuses on case-generation correctness, accepted policy, runtime boundedness and traceable outputs. OpenFOAM internals are not claimed as repository-native implementation.
