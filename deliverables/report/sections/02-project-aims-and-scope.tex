\section{Project Aims and Scope}

The project aim is to reconstruct tsunami propagation and local coastal-defence loading in a traceable, event-grounded workflow. The current status is:

\begin{itemize}
  \item theoretical 2D--3D model: complete;
  \item G6 implementation verification: complete;
  \item real-event integration: complete;
  \item observational validation: not yet complete;
  \item calibration methodology: defined in this report;
  \item physical calibration: not started;
  \item FSI, damage/failure, porous official breakwater representation and ML optimisation: future work.
\end{itemize}

The report therefore uses status terms carefully. \emph{Implemented} means present in repository or adopted backend configuration. \emph{Numerically verified} means tested by unit, benchmark or accepted run evidence. \emph{Real-event integrated} means the 2011 Tohoku source-to-Kamaishi workflow has been executed through the G6 replay. \emph{Validated} and \emph{calibrated} are reserved for future comparison against approved observations and subsequent parameter updates.
