\section{Reproducibility and Traceability}

The calibration baseline commit is \texttt{319d347644f0fe057ca2faa66ca5e324e10b5a21}. Major PRs include the pre-WBS baseline capture, Regional2D closures, Kamaishi delivery integration and PR \#274 for G6 closure.

The replay schema is 1.1.0, the boundary mode is \texttt{open\_ocean\_damped}, the coordinate reference is EPSG:32654, the event source is the 2011 Tohoku finite-fault source, and the terrain source for the G6 baseline is ETOPO 2022. The accepted replay interval is 245--545 s in source time and 0--300 s in Local3D shifted time.

Verification evidence is stored in the repository and external simulation evidence trees. This section is documentation evidence toward reproducibility; it is not itself the complete reproducibility bundle.
