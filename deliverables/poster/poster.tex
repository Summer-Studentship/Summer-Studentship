  \begin{PosterBox}{Why this matters}
    Tsunami-defence assessment needs local impact predictions that are physically linked to an event-scale source. A full 3D simulation from the earthquake source to the coast is not practical for routine design studies, while a purely depth-averaged model cannot resolve local inundation structure, forces, moments or defence interaction.

    \begin{CalloutBox}
      \textbf{Poster message.} The project builds an auditable one-way hybrid framework: a Regional2D model carries the Tohoku event toward Kamaishi, then Local3D OpenFOAM replay resolves local free-surface impact under the exported forcing.
    \end{CalloutBox}
  \end{PosterBox}

  \begin{PosterBox}{Aim and objectives}
    \textbf{Aim:} establish a validated event-reconstruction framework that can later support comparative assessment of coastal-defence configurations.

    \begin{itemize}
      \item Reconstruct coseismic tsunami generation from the 2011 Tohoku event.
      \item Propagate the wave through a source-to-coast Regional2D corridor.
      \item Export physically consistent nearshore forcing at a Kamaishi coupling interface.
      \item Replay that forcing in a Local3D URANS--VOF model for local impact.
      \item Quantify uncertainty through verification, convergence, calibration and validation gates.
    \end{itemize}
  \end{PosterBox}

  \begin{PosterBox}{Mathematical model}
    The Regional2D component solves a depth-averaged nonlinear shallow-water system in conservative form:
    \[
      \partial_t h + \nabla\!\cdot(h\mathbf{u}) = 0,
    \]
    \[
      \partial_t(h\mathbf{u}) +
      \nabla\!\cdot\!\left(h\mathbf{u}\otimes\mathbf{u}
      + \frac{1}{2}g h^2\mathbf{I}\right)
      = \mathbf{S}_{b}+\mathbf{S}_{f}+\mathbf{S}_{eq}.
    \]

    The Local3D replay uses an incompressible two-phase URANS--VOF formulation:
    \[
      \nabla\!\cdot\mathbf{U}=0,\qquad
      \partial_t(\rho\mathbf{U})+\nabla\!\cdot(\rho\mathbf{U}\otimes\mathbf{U})
      =-\nabla p+\nabla\!\cdot\tau+\rho\mathbf{g},
    \]
    \[
      \partial_t\alpha+\nabla\!\cdot(\alpha\mathbf{U})
      +\nabla\!\cdot\!\left(\alpha(1-\alpha)\mathbf{U}_c\right)=0.
    \]

    One-way coupling maps Regional2D free-surface elevation and depth-averaged momentum histories to the 3D inlet boundary. Feedback from Local3D to the Regional2D field is outside the current baseline.
  \end{PosterBox}

  \begin{PosterBox}{Verification and numerical findings}
    The poster baseline reports the project honestly: verification evidence has advanced, but full convergence, calibration and validation are not complete.

    \begin{itemize}
      \item G6 established the theoretical hybrid model baseline and accepted real Kamaishi Local3D replay evidence.
      \item C1A Regional2D convergence work corrected a previous fine-mesh construction ambiguity.
      \item The latest Regional ladder reuses h1000 and adds h900 and h800 full 600 s runs.
      \item The medium-to-fine forcing waveform comparison still exceeds the 2\% qualification target.
    \end{itemize}

    \begin{CalloutBox}
      \textbf{Current conclusion:} Regional forcing-waveform convergence is \textbf{not yet qualified}; no production mesh or timestep policy is selected from C1A.
