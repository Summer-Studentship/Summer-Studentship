  \begin{PosterBox}{Why this matters}
    Tsunami-defence assessment needs local impact predictions tied to a real event-scale source. Full source-to-coast 3D simulation is impractical for routine studies, while regional depth-averaged propagation cannot resolve detailed local vertical flow, free-surface deformation or structure loading.

    \begin{TightNoteBox}
      \textbf{Core idea:} a hybrid \(2\mathrm{D}\rightarrow3\mathrm{D}\) framework connects efficient regional propagation with local URANS--VOF impact response.
    \end{TightNoteBox}
  \end{PosterBox}

  \begin{PosterBox}{Aim and objectives}
    \textbf{Aim:} Establish a computational framework for reconstructing and validating real tsunami events, then reuse validated event forcing for Local3D coastal-impact and tsunami-defence studies, providing a basis for future structural and data-driven optimisation.

    \begin{itemize}
      \item Reconstruct the 2011 Tōhoku source from real event/terrain data.
      \item Propagate the event through a verified Regional2D NLSWE corridor.
      \item Establish observation-based historical-validation methodology.
      \item Demonstrate one-way transfer into Local3D URANS--VOF.
      \item Define response quantities for future defence comparison.
    \end{itemize}
  \end{PosterBox}

  \begin{PosterBox}{Verification Method}
    \textbf{Model consistency:} research formulation \(\rightarrow\) implementation traceability \(\rightarrow\) no required mismatch.

    \vspace{1.5mm}
    \textbf{Controlled Regional verification}
    \begin{itemize}
      \item manufactured solution \(\rightarrow\) \Chip{FIRST-ORDER BASELINE VERIFIED}
      \item limited-linear formulation \(\rightarrow\) \Chip{SECOND-ORDER LIMITED-LINEAR VERIFIED}
      \item smooth-wave benchmark: amplitude error reduced \(5.35\times\); phase-proxy error reduced \(17.43\times\).
    \end{itemize}

    \vspace{1mm}
    \textbf{Real-event fidelity:} event refinement and projection-only diagnosis characterise terrain/source fidelity as the dominant current limitation.

    \begin{TightNoteBox}
      \textbf{Real-event forcing:} best available, numerically uncertain.
    \end{TightNoteBox}

    \textbf{Hybrid / Local evidence:} replay consistency, reflection benchmark, runtime boundedness, \(y^+\) checks, probes and force/moment extraction.
  \end{PosterBox}

  \begin{PosterBox}{Current Achievements}
    \begin{itemize}
      \item Regional2D implementation traced consistently to the research formulation.
      \item First-order baseline and limited-linear second-order formulation verified.
      \item Real 2011 Tōhoku \(\rightarrow\) Kamaishi Regional2D reconstruction completed.
      \item Terrain/source fidelity characterised as the present real-event spatial limitation.
      \item One-way Regional2D\(\rightarrow\)Local3D replay framework implemented and demonstrated.
      \item Accepted Local3D no-defence and simple-rigid-barrier replay evidence includes free-surface/probe and force/moment outputs.
      \item Historical observation catalogue and validation methodology established.
    \end{itemize}
  \end{PosterBox}

  \begin{PosterBox}{Next Steps}
    \begin{enumerate}
      \item Improve source/terrain fidelity and refine or extend the validation domain where needed for observation colocation.
      \item Perform uncalibrated historical comparison, then documented calibration and holdout validation.
      \item Resolve current-generation Local3D VOF replay boundedness before adopting latest Regional forcing for impact studies.
      \item Execute no-defence / defence impact comparisons using agreed loading, overtopping, inundation and transmission metrics.
      \item Extend toward FSI, structural resilience, impact-response databases and future ML optimisation/design.
