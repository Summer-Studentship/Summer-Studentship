# Research Showcase Poster

## Final deliverable

The canonical Research Showcase poster source is `poster.html`.

The submitted v35 HTML is the final visual and design authority for the poster.
It must be preserved byte-for-byte when archived, reviewed or redistributed.
The file is intentionally self-contained and includes embedded raster assets and
the inline centreline-bathymetry SVG.

## Format

The poster is an A0 portrait design: 841 x 1189 mm.

The HTML uses a fixed design coordinate system of 1448 x 2048. It is not a
browser-responsive redesign, and responsive reflow is not intended.

## Design authority

`poster.html` is the authoritative HTML/SVG source with embedded raster assets.
Its source font stack is:

```text
"UCL Sans", Aptos, Arial, Helvetica, sans-serif
```

The approved layout, palette, masthead, logo placement, content, captions,
workflow state, project-trajectory state, references, print CSS and preview
controls are part of the archived source.

## Viewing and reproduction

Open `poster.html` directly in a local Chromium-compatible browser to view the
preview controls and inspect the poster.

Do not treat a newly rendered PDF as the frozen submission artifact.

## Historical TeX source

`poster-legacy.tex` is retained only as a historical scaffold. It is not the
final poster design authority and should not be used to reconstruct or replace
`poster.html`.

## Metadata and privacy

Submitted poster deliverables must remain free of generative-tool metadata,
service URLs, tracking links, temporary sandbox paths, local hostnames and
scratch-workspace references.

The exact submitted PDF should be treated as the frozen submission artifact only
if that approved file is present and its provenance has been verified. No exact
submitted PDF is archived here.
